**src/main.rs**

*Purpose:* Entry point for training an admissible language model from a text corpus. It parses command‑line arguments, loads the corpus (or checks its quality if `--dump-corpus` is set), initializes or resumes a language model (`Model`), trains it using hyperparameters defined in `TrainConfig`, and saves intermediate summaries/ledger.

*Principal ideas:*  
- Parses CLI flags to configure training parameters.  
- Loads or validates the input corpus based on token size relative to `--block-size`.  
- Instantiates a `Model` (either from a checkpoint if `--resume` is provided, otherwise creates a new model).  
- Trains the model with specified steps and batch size using `TrainConfig`.  
- Saves training ledger and final model.  
- Generates a sample sequence starting from a seed context of length `--block-size`, sampling up to `--sample-len` tokens with temperature 0.8.

*Important dependencies:*  
- `data::Corpus` for corpus loading/validation.  
- `model::Model` for language modeling operations.  
- `rand::{Rng, SeedableRng}` for random number generation during training and sampling.  
- Standard library types (`std::collections::HashMap`, `std::path::PathBuf`) for argument parsing and file handling.
