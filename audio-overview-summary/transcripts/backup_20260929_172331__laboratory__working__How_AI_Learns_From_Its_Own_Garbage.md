**Experimental Blueprint: Testing Flyxion’s Continuation Geometry Theory**

### 1. Semantic Labeling Experiment

**Objective:**  
To test whether the definition of a fork can be divorced from token probabilities by clustering divergences based on actual semantic algorithmic strategy before measuring SSD (Semantic Structure Distillation) treatment.

**Procedure:**
- **Step 1:** Identify specific points in code where forks occur, e.g., line 15 where the program can branch into either merge sort or quick sort.
- **Step 2:** Use a human expert or advanced semantic analyzer to verify that both branches (merge sort and quick sort) lead to fully functioning programs based on software engineering principles.
- **Step 3:** Trace probability mass in the neural network back to this exact divergence point.
- **Step 4:** Run SSD training and measure if the model preserves the specific semantic branching structure.

**Evaluation Criteria:**
- Does the model maintain distinct branches (semantic forks) without conflating them with token probabilities?
- Are both valid implementations correctly represented in the model’s internal representation?

### 2. Corrupted Data Stress Test

**Objective:**  
To determine whether structured prefixes rather than coherent whole sequences drive performance improvements when exposed to corrupted data.

**Procedure:**
- **Step 1:** Prepare three separate training runs using identical datasets:
  - **Model One (Prefix-only):** Train on only the coherent problem restatement prefixes, discarding any degraded portions.
  - **Model Two (Corrupted Suffixes):** Train on only the corrupted babbling suffixes, ignoring correct prefixes.
  - **Model Three (Randomized Sequences):** Train on fully shuffled randomized token sequences with identical vocabulary distribution but zero syntactic structure.
- **Step 2:** Evaluate performance improvements using a standard benchmark test.

**Hypothesis:**
- If Model One shows an exact 10% performance boost similar to the original stress test, while Models Two and Three show no improvement, Flyxion’s theory is validated. This would indicate that local regularities (structured prefixes) drive performance, not holistic properties of entire sequences.

### 3. Cross-Scale Bridge Ablation

**Objective:**  
To assess whether truncated prefix models can achieve comparable performance to perfect student models by reshaping geometry rather than learning correctness.

**Procedure:**
- **Step 1:** Train four identical base models (Student Models) on distinct data sets:
  - **Model A (Perfect Student):** Trained on fully correct, verified solutions.
  - **Model B (Confident Liar):** Trained on syntactically valid but mathematically incorrect code.
  - **Model C (Truncated Prefix):** Trained only on locally coherent prefixes without full completion.
  - **Model D (Distracted Student):** Trained on correct sequences from unrelated problems.
- **Step 2:** Match token count and optimization steps across all models for a fair comparison.
- **Step 3:** Evaluate performance using the live code bench test.

**Expected Outcomes:**
- If Flyxion’s theory holds, Model C (Truncated Prefix) should perform almost as well as Model A (Perfect Student), indicating that local structural information is sufficient to pave guardrails for correct outputs without needing full logical correctness.
- This would challenge traditional views of AI learning as purely knowledge acquisition and suggest that reshaping geometry can be the primary driver of capability.
