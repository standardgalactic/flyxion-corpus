**Curry-Howard Correspondence Explained**

The Curry-Howard correspondence is a profound concept linking computer science and logic. It posits that:

1. **Program Type Signatures ↔ Logical Propositions**: The type signature of a program (e.g., `int -> int` for a function taking an integer and returning an integer) corresponds to a logical proposition (e.g., "if you have an integer, then you can produce another integer"). 

2. **Programs as Proofs**: A computer program itself serves as the proof that the proposition it represents is true. This means writing code in Lean4 isn't just about functionality; it's also about proving mathematical truths at compile time.
