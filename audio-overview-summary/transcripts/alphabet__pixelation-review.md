# alphabet/pixelation-review

Summary:

The audio overview critiques the degradation of traditional visual standards (e.g., the galactic alphabet) into pixelated formats, using Mario’s evolution as an illustrative example. It expresses nostalgia for older operating systems like Windows 3.1 and DOS while criticizing contemporary software bloat. The core thesis is a speculative vision for creating an OS based on Unison programming language’s abstract syntax trees, envisioning navigation through a three-dimensional universe of nested bubbles—a concept that prioritizes novelty over usability. This idea extends to proposing a global knowledge graph where users adjust settings via arbitrary expertise, drawing an unexpected parallel to the cosmic microwave background and suggesting chaotic parameter calibration akin to “whack-a-mole.” The overview also touches on Unison’s obscurity (notably absent from Wikipedia), framing it as both a challenge and a source of self-doubt. Overall, the essay presents a defiant stance against perceived technological progress, emphasizing resistance through imaginative yet impractical solutions.
